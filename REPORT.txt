# 1. Временные характеристики стандартного алгоритма Merge Sort

 График "Standard Merge Sort Performance"  демонстрирует следующие закономерности:

-  Сложность O(n log n) : Все три типа массивов показывают предсказуемую логарифмически-линейную зависимость времени выполнения от размера массива, что соответствует теоретической оценке сложности алгоритма.

Наблюдается следующая иерархия производительности:
  -  Случайные массивы : Наибольшее время выполнения, что объясняется максимальным количеством операций сравнения и перемещения элементов
  -  Обратно отсортированные массивы : Время выполнения на 3-7% меньше, чем у случайных массивов, возможно, благодаря предсказуемости паттерна сравнений
  -  Почти отсортированные массивы : Похожая на reverse производительнсоть, что обусловлено минимизацией операций слияния за счет частичной упорядоченности

Несмотря на различия в абсолютных значениях времени, все три типа массивов сохраняют одинаковую асимптотическую сложность, подтверждая теоретические ожидания.

## 3. Детальный анализ влияния порога переключения

 График "Hybrid Sort Performance for Different Thresholds"  выявляет нетривиальную зависимость эффективности от величины порога:

-  Threshold=5 : 
Максимальная эффективность для малых массивов (500-2000 элементов)
Чрезмерное увеличение глубины рекурсии для средних массивов, что снижает общую эффективность
-  Threshold=10-20 :
Наибольший выигрыш в производительности для широкого диапазона размеров
Сохранение преимущества над стандартным алгоритмом для всех типов массивов
Наиболее универсальные значения для общего применения

-  Threshold=30-40 :
Улучшение производительности для средних и крупных массивов
Для малых массивов выигрыш сокращается
Уменьшение накладных расходов рекурсии при сохранении преимуществ Insertion Sort

-  Threshold=50 :
Наблюдается насыщение выигрыша, а для некоторых размеров даже небольшое ухудшение относительно меньших порогов
При дальнейшем увеличении порога преимущество гибридного алгоритма исчезает

# Выводы

# 1. Нелинейная зависимость эффективности от порога

Максимальный выигрыш достигается не при минимальных порогах, а в диапазоне около 50 элементов, что противоставляет интуитивному ожиданию "чем меньше порог - тем лучше".

# 2. Практические рекомендации по выбору порога

На основе проведенного анализа сформулированы уточненные рекомендации:

-  Для систем общего назначения : Порог 40 элементов обеспечивает максимальный выигрыш для наиболее распространенных размеров массивов
-  Критическое значение : Пороги выше 45 элементов не рекомендуются, так как преимущество гибридного алгоритма становится незначительным

# 3. Теоретическое обоснование наблюдаемых закономерностей

Полученные результаты согласуются с теоретическими ожиданиями:
- Порог должен быть достаточно мал, чтобы использовать преимущества Insertion Sort
- Порог должен быть достаточно велик, чтобы минимизировать накладные расходы рекурсии

# Заключение

Гибридный алгоритм Merge+Insertion Sort демонстрирует значительное и стабильное улучшение производительности при правильном выборе порога переключения. Ключевым открытием исследования является определение оптимального диапазона порогов 40-50 элементов, который обеспечивает максимальный выигрыш для широкого спектра практических задач.
